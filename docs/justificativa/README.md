# Justificativa técnica do KernelPlay

Documento produzido em 19/11/2026, com revisão documental em 26/11/2026. A descrição das regras tem como base o código da versão `9989806`. A edição atual inclui registro de IA, identificação do agente sem versão de modelo não comprovada, análise das heurísticas de Nielsen e esclarecimento sobre a carga fixa.
